Questionamentos principais: 

Problema 1 — Fatoração / divisores
O gargalo dominante é o loop de divisão tentativa até √N. Cada iteração precisa de um teste de divisibilidade (X % D) e a diferença crítica é:
Usando opcodes 163/164 (div/mod software): cada divisão custa O(log N) microciclos internamente — são dezenas de µc por passo do loop.
Usando opcodes 168/169 (div/mod combinacional em 1 µc cada): o custo por iteração cai para mod (1) + branch (2) + div (1) = 4 µc. Ganho de 5–10×.

Problema 2- Não há uma função IsPrimo nativo trabalhando apenas com portas lógicas ou bit masks. Esse é um problema que faz que o processador temha que se dividir entre dois problemas achar o proximo primo e depoois dividir, achar o proximo primo deveria ser mais facil.

Problemas 3 e 4:
Soma de divisores: loop O(N) em vez de O(√N)
Loop d de 1 até N+1 é desnecessário. Iterando até √(N+1) e somando d + (N+1)/d quando d | (N+1), reduz de O(N) para O(√N) iterações. Requer opcode 169 (mod hw) + 168 (div hw).
CRÍTICO
Teste de primalidade sem otimização de salto 2/3
Testar apenas d=2 e depois d=6k±1 (k=1,2,…) reduz iterações em ~3×. No firmware: pré-teste d=2 com opcode 76 (1 bit, 2 µc), depois incremento +6 no divisor (opcode 88/89)

Sugestão: Usar CALL/RET (102/105) para a subrotina de primalidade evita duplicar microcódigo nos dois contextos.

Problema 4 — Sort de 4 bytes dentro de um word
O gargalo mais estrutural. Dois problemas sobrepostos:

Pressão de registradores: 4 bytes extraídos + acumulador de resultado requerem os 5 registradores (X, Y, H, Z1, Z2) quase todos ocupados. Qualquer spill para memória custa 2+ µc extras.
Branches de comparação dominam: insertion sort com loop tem até 6 comparações, cada uma custando 1 (cmp) + 2 (branch) + 1 (swap) = 4 µc. Usar um sorting network fixo de 4 elementos (5 comparadores "compare-and-swap" em posições fixas, sem branches de controle de loop) elimina o overhead de branch de iteração e dá custo determinístico. O opcode 48 (SWAP X↔Y em 1 µc via ALU dupla) é central aqui — sem ele, um swap custaria 3 µc
